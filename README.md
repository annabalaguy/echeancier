# Échéancier

Outil de trésorerie pour micro-entrepreneuse : solde « vraiment à toi », URSSAF et TVA calculées automatiquement, projection sur 90 jours, import de relevés CSV, export calendrier.

**Utiliser l'appli : https://annabalaguy.github.io/echeancier/**

- Un seul fichier (`index.html`), aucune dépendance, aucun serveur.
- Les données restent dans le navigateur (localStorage). Pense à sauvegarder (bouton « Sauvegarder »).
- Mode d'emploi détaillé : [LISEZMOI.txt](LISEZMOI.txt).
